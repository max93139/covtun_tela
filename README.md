# Daily Telegram Poster (GitHub Actions)

Этот проект автоматически выбирает случайное предложение из файла `phrases.txt` и отправляет его в Telegram в 23:00 по московскому времени (UTC+3).

## Структура проекта
* `main.py` — основной Python-скрипт.
* `phrases.txt` — список фраз (по одной фразе на строку).
* `requirements.txt` — зависимости проекта.
* `.github/workflows/daily_post.yml` — сценарий GitHub Actions, запускающий код по расписанию.

## Как запустить

### Шаг 1. Настройка Telegram
1. Создайте бота через **@BotFather** в Telegram и скопируйте его токен.
2. Добавьте бота в свою группу / канал и назначьте его администратором.
3. Получите ID вашей группы / канала (например, с помощью бота **@JsonDumpBot**). ID группы обычно начинается с минуса (например, `-1001234567890`).

### Шаг 2. Настройка репозитория GitHub
1. Создайте новый репозиторий на GitHub.
2. Инициализируйте Git в локальной папке проекта и отправьте код на GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   git push -u origin main
   ```
3. В настройках вашего репозитория на GitHub перейдите в **Settings** -> **Secrets and variables** -> **Actions** -> **New repository secret**.
4. Добавьте секреты:
   * `TELEGRAM_BOT_TOKEN` — токен вашего бота.
   * `TELEGRAM_CHAT_ID` — ID группы / канала.

### Шаг 3. Редактирование фраз
Просто отредактируйте файл `phrases.txt`, добавив туда свои предложения (каждое предложение с новой строки), сделайте коммит и отправьте изменения на GitHub.

### Ручной запуск
Вы можете запустить скрипт в любой момент во вкладке **Actions** на GitHub, выбрав сценарий **Daily Telegram Poster** и нажав кнопку **Run workflow**.
